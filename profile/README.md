# Bangmun

관광 동호회와 방문 단체를 위한 방문기록 및 통계 서비스입니다.

## About

Bangmun은 방문기록을 관리하고, 누적된 데이터를 통계와 순위로 확인할 수 있도록 만든 서비스입니다.

현재 실제 운영 환경에서 사용되고 있으며, 기존 서비스를 유지하면서 차세대 버전을 개발하고 있습니다.

## Features

- 방문기록 작성, 수정 및 검색
- 기간별 방문 통계와 비교
- 방문자 및 장소별 순위
- 방문기록 데이터 내보내기
- 동호회 및 계정 관리
